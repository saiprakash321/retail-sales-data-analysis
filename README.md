# Retail Sales Data Analysis Using Python

## Project Overview

This project analyzes the Sample Superstore retail dataset using Python. The goal is to explore the data, check data quality, create visualizations, and identify useful business insights about sales and profit.

## Dataset

- **Dataset name:** Sample Superstore
- **File:** `Sample - Superstore.csv`
- **Records:** 9,994 rows
- **Columns:** 21

The dataset contains information about orders, customers, products, sales, discounts, shipping, and profit.

## Tools and Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Tasks

1. **Load and Explore the Dataset** — inspect the dataset structure, columns, data types, and summary statistics.
2. **Clean the Dataset** — check for missing values, duplicates, data types, and unusual values.
3. **Data Visualization** — create charts to explore sales, profit, regional performance, and sales distribution.
4. **Find Five Insights** — analyze product categories, regions, top-selling products, and the relationship between sales and profit.

## Key Findings

- Technology recorded the highest total sales among the product categories.
- Technology recorded the highest total profit among the product categories.
- The West region had the highest total sales.
- The Canon imageCLASS 2200 Advanced Copier was the top product by total sales.
- The highest individual sales record also showed a loss, demonstrating that high sales do not always guarantee high profit.

## Files in This Repository

- `Data_Analysis_Task.ipynb` — notebook containing the analysis, code, and visualizations.
- `Sample - Superstore.csv` — dataset used for the project.

## How to Run the Project

1. Install Python and Jupyter Notebook.
2. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn
   ```

3. Download or clone this repository.
4. Keep the notebook and CSV file in the same folder.
5. Open `Data_Analysis_Task.ipynb` in Jupyter Notebook.
6. Run the cells from top to bottom.
