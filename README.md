# Retail Sales Data Analysis Using Python 📊🐍

A practical data analysis project focused on exploring, cleaning, visualizing, and interpreting retail sales data using Python, Pandas, NumPy, Matplotlib, and Seaborn.

This repository contains my learning and practical implementation of dataset exploration, data quality checks, data cleaning, data visualization, and business insight generation using the Sample Superstore dataset.

## 🎯 Project Objectives

The main goal of this project is to develop a practical understanding of data analysis and learn how to extract meaningful information from real-world retail data.

- Understand the structure and features of a retail dataset.
- Load and inspect data using Pandas.
- Explore rows, columns, data types, and statistical summaries.
- Identify missing values and duplicate records.
- Check and correct data types.
- Understand the importance of data cleaning.
- Visualize sales and profit across product categories.
- Compare sales performance across regions.
- Examine sales trends over time.
- Analyze the relationship between sales and profit.
- Understand the distribution of sales values.
- Identify five meaningful business insights.
- Present findings using Python code, charts, and written explanations.

## 📊 Dataset

**Dataset:** Sample Superstore

**File:** `Sample - Superstore.csv`

The dataset contains 9,994 records and 21 columns.

It includes information about:
- Orders and order dates
- Shipping details
- Customers and customer segments
- Product categories and sub-categories
- Sales and quantities
- Discounts and profit
- Regions and locations

The dataset is used to explore retail performance and identify patterns in sales, profit, products, and regional activity.

## 📈 Analysis Workflow

Dataset Loading → Dataset Exploration → Data Quality Checks → Data Cleaning → Data Visualization → Business Insight Generation → Final Conclusions

## 🔍 Key Findings

Based on the results obtained during the analysis:

- Technology recorded the highest total sales among the product categories.
- Technology recorded the highest total profit among the product categories.
- The West region had the highest total sales.
- The Canon imageCLASS 2200 Advanced Copier was the top product by total sales.
- One of the highest-sales transactions also recorded a loss, showing that high sales do not always guarantee high profit.

These findings should be interpreted alongside the corresponding notebook outputs.

## ▶️ How to Run the Project

### Prerequisites
- Python installed on your system
- Jupyter Notebook or JupyterLab

### Install Required Libraries

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### Execution Steps

1. Clone or download this repository.
2. Keep the notebook and CSV dataset in the same folder.
3. Open a terminal in the project directory.
4. Start Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

5. Open `Data_Analysis_Task.ipynb`.
6. Run the notebook cells in order from top to bottom.
